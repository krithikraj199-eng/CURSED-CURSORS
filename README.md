# CURSED CURSORS ⚡🖱️

A web application for exploring, customizing, and exporting animated & themed custom cursed cursors.

## 🚀 Features

- **Massive Cursor Library**: Cyberpunk, Anime, Aesthetic, Retro, Meme, Cute, Gaming, and Special FX presets.
- **Real-Time Cursor Canvas & Customizer**: Interactive layer editor, multi-layer effects, rotation, pulse, trails, glow, and animations.
- **AI Cursor Generation**: Prompt-assisted cursor design.
- **Export Formats**: CSS snippet, SVG, PNG, and Windows/Web packages.
- **Interactive Sandbox & Games**: Test your cursed cursors with minigames and interactive elements.

## 🛠️ Run Locally

**Prerequisites:** Node.js (v18+)

1. Clone repository:
   ```bash
   git clone https://github.com/krithikraj199-eng/CURSED-CURSORS.git
   cd CURSED-CURSORS
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables (optional for AI generation):
   Copy `.env.example` to `.env.local` and add your `GEMINI_API_KEY`.

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
